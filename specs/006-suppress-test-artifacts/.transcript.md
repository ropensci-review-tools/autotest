# Session Transcript: suppress-test-artifacts

## Session Overview
Triggered by `make knitr` leaving untracked `README-*.png` files and literal ANSI escape
noise in the rendered `README.md`. The session scoped, planned, and implemented a fix
covering plot suppression, progress-bar noise, and related build hygiene.

## Design Decisions Made

### Decision 1: Suppress plot generation entirely rather than embed or redirect
**Chosen:** Plots produced as side effects of running documented examples/mutation tests
should never appear in rendered output at all, rather than being generated into a
tempdir or committed as real documentation assets.
**Rationale:** The plots are incidental side effects of testing, not intentional
documentation figures; mpadge additionally flagged that testing arbitrary real-world
packages leaves stray `Rplots.pdf` residue, indicating the same root cause needed a
general (not README-specific) fix.
**Tradeoffs:** None — no legitimate use case for these plots was identified.
**Proposed by:** joint

### Decision 2: Fix at the root cause (execution sites), not per-document chunk options
**Chosen:** Wrap every place arbitrary package/example code actually executes with a
shared discarding-graphics-device helper, rather than adding `fig.show = "hide"` to each
`.Rmd` chunk.
**Rationale:** A per-chunk fix would not address the general `Rplots.pdf` complaint, and
would need to be re-applied to every new document. The audit found the actual root cause
was inside the external `typetracer` dependency's example-execution, reachable by wrapping
this package's own call site into it.
**Tradeoffs:** More execution sites to find and wrap; mitigated by a full audit (T006-5).
**Proposed by:** agent

### Decision 3: Vignettes included in scope alongside README
**Chosen:** Apply the same fix and cleanup to both `vignettes/*.Rmd` files, which shared
the identical copy-pasted `fig.path` bug.
**Rationale:** mpadge preferred consistency over narrow scoping to avoid leaving a known
latent duplicate of the same bug.
**Proposed by:** joint

## Tradeoffs Considered
- Embedding real plots as committed GitHub-visible assets vs. suppressing entirely: mpadge
  chose suppression, since the plots are noise rather than documentation.

## Open Questions
- None remaining; the implementation-time audit (T006-5) resolved the plan's open question
  about further execution sites, uncovering additional direct `do.call(x$fn, ...)` sites and
  the actual root cause inside `typetracer::trace_package()`.
